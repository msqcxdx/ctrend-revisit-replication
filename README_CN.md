# CTREND Revisit：公开复现材料

这是从固定研究版本筛选出来的**独立公开仓库**，不是私有研究主档的镜像。仓库不附带 CMC 逐币行情，也不包含十八组完整 MATLAB 运行树；克隆仓库不等于可以立刻从原始数据完整重算。

研究区分三件事：原程序 M0、只修特定未来信息与结算通道的 M2、进一步核对统计定义和组合会计的 M1。已识别的直接前视问题值得修复，但 M2 的结果并非“主要收益消失”。样本支持、风险、资产暴露与其他定义同样重要。十八组组合来自同一历史数据，不是十八次独立市场实验。

阅读顺序：[论文复现说明](PAPER_REPLICATION.md) → [快速开始](QUICKSTART.md) → [数据可得性](DATA_AVAILABILITY.md) → [已知限制](KNOWN_LIMITATIONS.md)。主文及附录表图的位置见 [映射表](TABLE_FIGURE_MAP.csv)。

P0/P1 区分是否增加统一缺失值预处理；M0/M2/M1 区分方法修正范围；D0/D1/D2 区分全资产、排除 INNBCL、再排除冻结事件资产。D1/D2 是事后敏感性分析，不能解读为实时可实施的筛选规则。

无 CMC 数据和 MATLAB 时可执行 `python3 scripts/public_quickcheck.py` 核对公开材料身份，再运行 `./reproduce_tables.sh`：后者从原作者公开工作簿重新计算因子统计量，并用已保存的十八组**汇总值**重排主表和绘制两张明确标注的诊断图。它没有重新训练十八组模型，也没有重画原论文图形。`./run_all.sh test` 是公开包的离线代码检查。

如有合法取得的完整输入、与研究版本一致的两个外部 MATLAB helper，以及 MATLAB R2023b Update 11 和所需工具箱，可用 `./reproduce_everything.sh` 从头执行全部十八组；缺少任一项，生产前检会报错。公开包尚未宣称完成一次新的、干净环境下的完整重估。步骤和输出路径见 [快速开始](QUICKSTART.md)。私有研究仓库及已验收结果没有被本次公开导出修改。
